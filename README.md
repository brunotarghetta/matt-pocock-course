# Matt Pocock Skills

This repository uses the skills listed in `skills-lock.json`. From the repository root, install them with:

```bash
npx skills@latest install
```

This restores the locked skills into `.agents/skills/` and links them to the coding agents available on your machine. The `.agents/` directory is generated locally and is ignored by Git; commit changes to `skills-lock.json` when the selected skills or their versions change.
